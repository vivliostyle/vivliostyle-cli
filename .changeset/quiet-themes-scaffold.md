Move `create-vivliostyle-theme` into this repository as a thin wrapper around the `vivliostyle theme create` command. `npm create vivliostyle-theme@latest` now scaffolds a theme package with the same prompts, template, and options as Vivliostyle CLI, and the package version follows `@vivliostyle/cli` from now on.
